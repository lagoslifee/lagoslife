# OpenStreetMap derivative dataset

`ikoyi-starter.osm.json` contains a selective extract of OpenStreetMap road and
building data for the bounding box 6.4445,3.4240–6.4545,3.4360, fetched from
the Overpass API on 2026-10-10.

Data © OpenStreetMap contributors, available under the Open Database License
1.0: https://www.openstreetmap.org/copyright

This unencrypted, machine-readable file is the derivative database offered
alongside the produced game world. It may be used, modified, and redistributed
under the ODbL. The game code and original visual assets are separate works and
retain their respective licences.
