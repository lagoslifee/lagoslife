# OpenStreetMap derivative dataset

`lagos.world.json` and the per-tile files in `tiles/` are derived from
OpenStreetMap road, building, landuse and water data for Lekki Phase 1, the
Lekki-Ikoyi Link Bridge, Ikoyi and Victoria Island (Eti-Osa, Lagos). The source
extracts in `data/osm/` were fetched from the Overpass API on 2026-10-10.

Data © OpenStreetMap contributors, available under the Open Database License
1.0: https://www.openstreetmap.org/copyright

These unencrypted, machine-readable files are the derivative database offered
alongside the produced game world. They may be used, modified, and
redistributed under the ODbL. The game code and original visual assets are
separate works and retain their respective licences.
